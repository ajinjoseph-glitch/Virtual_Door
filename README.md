# Virtual Door 🚪

Your entire application is just a door.

**Click** → door opens.

Behind it is **another door**.

Keep clicking.

Eventually:

> **"Congratulations. You have achieved nothing."**

---

## 🎮 How to Play

1. Open `index.html` in your browser
2. Click the door
3. Witness the absurdity unfold
4. Achieve nothing

## 📋 Features

- ✨ Smooth 3D door opening animation
- 💬 Progressively sarcastic messages
- 🎨 Beautiful gradient design
- 🎯 Purposeless gameplay
- 📱 Fully responsive

## 🛠️ Customization

Edit `MAX_CLICKS` in `script.js` to adjust difficulty (how many doors before victory).

Edit messages array to customize the sarcastic commentary.
